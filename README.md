# Password Checker

A static website that rates password strength, checks it against known data breaches (Have I Been Pwned, k-anonymity: only the first 5 characters of the SHA-1 hash are sent), generates strong passwords, and has a dark/light toggle.

## Run locally
Open `index.html` in a browser (the breach check works best over https or `localhost`).

## Host on GitHub Pages
Upload `index.html`, `style.css`, `script.js` and `README.md` to a repository, then go to Settings > Pages > Deploy from a branch > `main` / root.
